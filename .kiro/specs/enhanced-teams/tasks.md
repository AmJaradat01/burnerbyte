# Implementation Plan: Enhanced Teams

## Overview

This plan implements 13 requirements for the enhanced teams feature in the BurnerByte platform. The implementation proceeds bottom-up: database migration first, then domain models, repository layer, service layer, RBAC changes, handler/routing layer, settings resolver integration, and finally wiring everything together in `cmd/api/main.go`. Each task builds incrementally on the previous, ensuring no orphaned code.

## Tasks

- [ ] 1. Create database migration 000033 for enhanced teams schema
  - [ ] 1.1 Create `migrations/000033_enhanced_teams.up.sql`
    - Enable `pg_trgm` extension with `CREATE EXTENSION IF NOT EXISTS pg_trgm`
    - Add `description TEXT`, `avatar_url TEXT`, `is_archived BOOLEAN NOT NULL DEFAULT FALSE`, `archived_at TIMESTAMPTZ` columns to the `teams` table
    - Create index `idx_teams_org_archived` on `(org_id, is_archived)` for filtered team listing
    - Create GIN trigram index `idx_teams_name_trgm` on `name` using `gin_trgm_ops` for case-insensitive search

    - Remove columns `archived_at`, `is_archived`, `avatar_url`, `description` from `teams`
