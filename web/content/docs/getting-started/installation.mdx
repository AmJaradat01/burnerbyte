## Prerequisites

| Requirement | Version |
|---|---|
| Go | 1.25+ |
| Node.js | 20+ with pnpm |
| Docker & Docker Compose | Latest |
| PostgreSQL | 16 (or use Docker) |
| Redis | 7 (or use Docker) |

## Clone the Repository

```bash
git clone git@gitlab.com:burnerbyte/burnerbyte.git
cd burnerbyte
```

## Copy Configuration File

The Docker images (`Dockerfile` and `Dockerfile.smtpd`) copy `config.yaml` into the image at build time. A fresh clone does not include this file, so you must create it before any Docker build:

```bash
cp config.example.yaml config.yaml
```

Edit `config.yaml` if you need to change defaults. For Docker Compose deployments most settings are overridden by environment variables — see [Configuration](/docs/getting-started/configuration).

## Start the Stack

`make docker-up` starts the **full stack** — PostgreSQL 16, Redis 7, MinIO, the API server, SMTP server, and the Next.js frontend — via `docker compose up -d`.

```bash
make docker-up
```

<Callout type="warn">
App containers (`api`, `smtpd`) will crash-loop if required secrets are not set. At minimum, set `JWT_SECRET` (and `BB_ENCRYPTION_KEY` for SSO/SMTP-password encryption) in a `.env` file before running. See [Docker Setup](/docs/getting-started/docker) for a full variable list.
</Callout>

To stop the stack: `make docker-down`

**Local development only:** If you want only the infrastructure services (postgres, redis, minio) and intend to run the API and frontend locally, run `docker compose up -d postgres redis minio` directly, then use `make run-api` and `cd web && pnpm dev`.

## Environment Configuration

```bash
cp .env.example .env
```

Edit `.env` with your values. At minimum, configure:

- `DATABASE_URL` — PostgreSQL connection string
- `REDIS_URL` — Redis connection string
- `JWT_SECRET` — A random 64-character string for signing tokens

See [Configuration](/docs/getting-started/configuration) for all available options.

## Run Migrations

```bash
make migrate-up
```

This applies all 43 database migrations, creating tables for users, organizations, teams, domains, inboxes, emails, attachments, webhooks, API keys, audit logs, sessions, SSO, analytics, and more.

## Install Frontend Dependencies

```bash
cd web && pnpm install
```

## Build (Optional)

For production builds:

```bash
# Backend
make build

# Frontend
cd web && pnpm build
```

This produces `bin/api`, `bin/smtpd`, and the Next.js standalone output.
