## Configuration Sources

BurnerByte loads configuration from three sources (in priority order):

1. **Environment variables** — Highest priority. Prefixed with `BB_` (e.g., `BB_SERVER_PORT`)
2. **`config.yaml`** — File-based config, searched in `.` and `/etc/burnerbyte/`
3. **Database overrides** — Runtime config stored in `system_configs` table (mailer + storage only)

Common variables like `DATABASE_URL`, `REDIS_URL`, `JWT_SECRET` are mapped directly without the `BB_` prefix.
