## Welcome

BurnerByte is a self-hosted temporary email platform built for teams that need disposable email addresses for testing, development, and QA workflows. It provides a complete solution with real-time email delivery, configurable attachment policies, webhooks, and a full RBAC system.

## Key Features

- **One-time setup wizard** — Admin account, org, SMTP, domain, team, branding, and invites
- **Multi-team, multi-domain** — Single org with teams scoped to specific domains
- **Full RBAC** — 6 roles across org and team levels
- **Real-time delivery** — WebSocket streaming for instant email notifications
- **Configurable attachments** — Policy inheritance from org → domain → team
- **Webhooks** — HMAC-SHA256 signed with retry and delivery logs
- **Scoped API keys** — Programmatic access with granular permissions
- **Audit logging** — Full activity trail with filtering and CSV export
- **Analytics** — Time-series charts and aggregate stats
- **SSO** — OIDC provider integration
- **Private inboxes** — Only the creator can access

## Architecture at a Glance

```
┌─────────────┐     ┌──────────────┐     ┌───────────┐
│  Next.js UI │────▶│   Go API     │────▶│ PostgreSQL│
│  (port 3000)│     │  (port 8080) │     └───────────┘
└─────────────┘     │              │────▶┌───────────┐
                    │  Chi Router  │     │   Redis   │
┌─────────────┐     │  + Workers   │     └───────────┘
│ Mail Server │────▶│              │────▶┌───────────┐
│  (external) │     └──────────────┘     │   MinIO   │
└─────────────┘                          └───────────┘
       │
       ▼
┌──────────────┐
│  Go SMTPD    │
│  (port 2525) │
└──────────────┘
```

Two separate Go binaries scale independently:
- **`cmd/api`** — HTTP API server + background workers
- **`cmd/smtpd`** — SMTP inbound server

| Layer | Technology |
|---|---|
