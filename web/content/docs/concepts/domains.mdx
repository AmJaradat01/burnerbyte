## Adding a Domain

Domains are added at the org level via the API:

```bash
POST /orgs/{orgId}/domains
{"domain_name": "test.example.com"}
```

The server generates a unique TXT verification record (e.g., `burnerbyte-verify=abc123`).

## DNS Verification

Two DNS records must be configured:

### MX Record

```
test.example.com.  MX  10  mail.yourserver.com.
```

### TXT Record

```
test.example.com.  TXT  "burnerbyte-verify=abc123"
```

## Verification Flow

1. **Manual trigger** — Click "Re-verify DNS" or call `POST /orgs/{orgId}/domains/{domainId}/verify`
2. **Auto-polling** — The frontend polls every 30 seconds while verification is pending
3. **Background worker** — The DNS recheck worker re-verifies all unverified domains every hour

Both MX and TXT must be verified before the domain can receive emails.

## Team Assignment

After verification, assign the domain to teams:

```bash
POST /orgs/{orgId}/teams/{teamId}/domains
{"domain_id": "...", "access_level": "full"}
```

Access levels: `full` (create inboxes + receive emails) or `read` (view only). Each assignment can override org-level settings (attachments, max size, inbox TTL).
